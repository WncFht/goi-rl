# 《掘地求升》强化学习与速通研究资料

更新日期：2026-10-20。目标是研究原版游戏的物理、可控环境和学习算法，逐步从可靠通关推进到低耗时通关。

## 阅读入口

1. [主报告：物理机制、环境审计、项目进展与算法路线](2026-10-20-掘地求升物理环境与速通算法调研.md)。先读第 1、3、5、8、10 节。
2. [环境接口与评估契约草案](环境与评估契约.yaml)。这是后续实现的建议规格，不是已经运行的环境配置。
3. [来源清单](sources/资料索引.tsv)。按优先级列出仓库、物理解释、教程、论文和跨游戏速通项目。
4. [源码快照清单](sources/source-manifest.json)。记录四个仓库的提交、选取文件、上游永久链接与 SHA-256。
5. [论文检索原始输出](sources/论文检索原始结果.md)。保留检索工具输出，正文另有针对本任务的阅读建议。

## 本地资料

| 目录／文件                              | 内容                                                      | 使用边界                           |
| --------------------------------------- | --------------------------------------------------------- | ---------------------------------- |
| `sources/code/miwate/`                  | 原版游戏接口、PPO、搜索、课程、SAC 混合数据实验与评估源码 | 选取的文本快照，不是完整可运行安装 |
| `sources/code/heuriz/`                  | SAC、数据管理、CUDA 雷达与预处理源码                      | 未收集地图资产；上游未附游戏插件   |
| `sources/code/vision/`                  | 截屏与鼠标控制、CNN-PPO、相机插件源码                     | 未运行游戏验证                     |
| `sources/code/level-importer/`          | BepInEx 地图导入与 Unity 工具源码                         | 用于阅读课程地图／泛化扩展接口     |
| `sources/hf-model-card.md`              | miwate 对应模型卡快照                                     | 成绩是作者报告                     |
| `sources/hf-model-api.json`             | 模型提交与发布文件列表                                    | 可核查权重、归一化等资产是否随附   |
| `sources/hf-chain.json`                 | 发布的分段策略切换表                                      | 不是单网络策略                     |
| `sources/hf-checkpoint-inspection.json` | 一个模型 ZIP 的目录和 JSON 字段检查                       | 未反序列化或执行权重               |
| `scripts/check_research.py`             | 文档链接、来源索引和源码哈希检查                          | 不检验游戏物理或算法成绩           |

本目录未安装游戏、编译模组或启动训练。原版物理参数、训练吞吐、恢复确定性、成功率与速通耗时都需要后续在指定游戏构建上实测。源码快照保留上游文本，研究建议和审计结论写在主报告中；公开可读不等于所有仓库都有明确的开放源代码许可证。

本地资料检查：

```bash
python scripts/check_research.py
```

开发依赖、格式化、提交 hook 和 CI 的使用见 [仓库维护](docs/README.md)。
